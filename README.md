# mrrua.com

A simple, modern dark-mode single-page website featuring personal rules and links.

## Features

- **Dark Mode Design**: Clean dark theme with modern aesthetics
- **Simple Layout**: Single page with rules and links
- **Responsive**: Works beautifully on all devices
- **Modern Typography**: Inter font family for clean readability

## Getting Started

Simply open `index.html` in your browser or serve it with a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000` in your browser.

## Customization

- **Links**: Update the href attributes in `index.html` for GitHub, LinkedIn, Resume, and Email
- **Rules**: Modify the rules list in `index.html` as needed
- **Colors**: Edit the CSS variables in `styles.css` under `:root`

## Browser Support

Modern browsers (Chrome, Firefox, Safari, Edge)
